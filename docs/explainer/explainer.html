mcpgraphy
Your agent's tools, mapped before it acts.
Learned, uncertainty-aware behavior graphs for MCP tools.

A tool list says what a tool is called.
Not when it works.

agent → edit_file(path="notes.md", …)
ENOENT: no such file or directory
agent → publish_release(release_id="demo-7")
STATE_CONFLICT: release cannot be published in its current state
agent → move_file(source="draft.md", destination="final.md")
ENOENT: no such file or directory, rename 'draft.md'
… retry … retry …
Errors, retries, and sometimes damage. The schema was never going to tell it.

It sits between the agent and the server.

Tools pass through unchanged. Before and after every call, the resource is read back. The evidence is kept.

No probing. No resets. Nothing extra touches your server. The agent's own calls are the evidence.

Tested applicability, never a guarantee. explain shows the exact calls and counterexamples behind each line.

Three policies. Observe, warn, or block.
