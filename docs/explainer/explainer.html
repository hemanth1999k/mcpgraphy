It sits between the agent and the server.

One line, on every read. The agent stops guessing. Ask explain and it shows the calls behind each word.

Three policies. Observe, warn, or block.

observe
log and learn. Nothing changes for the agent.
warn
pass everything through, add a note when evidence says it fails here.
block
refuse known failures and unapproved destructive calls, with the reason.
$ mcpgraphy wrap --adapter filesystem.json --policy block -- npx @modelcontextprotocol/server-filesystem ~/work
